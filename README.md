# Kettil Fastigheter

28 färdiga HTML-sidor med lokala bilder, originalets logotyp och typsnitt. Ingen installation behövs.

## Publicera på GitHub Pages
Packa upp ZIP-filen. Lägg innehållet i mappen kettil-fastigheter-github direkt i repots rot. Aktivera GitHub Pages från huvudgrenen och rotmappen. Alla interna länkar och bilder fungerar även under ett reponamn.

## Innehåll och funktioner
- Fullstor hero med Kettils egen bild av Hammargatan i Tranemo.
- Nio fastighetssidor med ortsfilter, fakta och bildgallerier.
- Hyresgästsidor, kontaktpersoner, intresseanmälan och felanmälan.
- Byggkonsult, Kettils koncept, sex referenskategorier och samarbeten.

Formulären öppnar ett mejlutkast i besökarens egen e-postapp. Besökaren måste själv skicka det. Felanmälan länkar också till företagets befintliga formulär. Ingen förfrågan skickas av denna webbversion.

Fastighetsbilder och fakta kommer från kettilfastigheter.se. Beståndet visas utan påståenden om aktuella vakanser, hyror eller recensioner. Wiléns väg visar visualisering och arkiverade byggbilder. Aktuell tillgänglighet behöver bekräftas av företaget.

style.css styr utseendet, script.js sköter meny, filter och galleri. Innehållet finns i respektive HTML-fil. Fontlicens finns i assets/FONT-LICENSE.txt.
